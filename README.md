# 班级班牌

把教室电脑的桌面变成一块班级班牌：实时显示当前时间、今日课表、上下课倒计时和值日安排；老师用手机就能往班牌上推消息，班牌会大字弹出并用语音念一遍。

用 C# / WPF 编写，运行在 .NET Framework 4.8 上，Windows 10 / 11  。

## 功能

- **桌面班牌**：三种显示方式可切换，不干扰老师正常使用电脑
- **今日课表**：自动判定「正在上 / 课间 / 午休 / 已放学」，显示距下课或距上课的倒计时和课程进度
- **今日值日**：按星期自动切换，显示姓名和分工
- **手机端推送**：浏览器打开即用，大字弹窗 + 中文语音播报，到点自动消失；标为紧急的消息需要手动确认
- **手机端维护数据**：课表、值日表、作息时间表都能在手机上改，保存后班牌立刻刷新
- **无操作全屏**：班牌收起后，长时间没人操作会全屏出现；检测到全屏应用（放视频、PPT 放映）时自动避让
- **深浅两套主题**：教室大屏用深色，普通显示器用浅色

## 两种界面

程序内置两套排版，按显示方式自动选用：

| 界面 | 用于 | 布局 |
|---|---|---|
| 宽屏版 | 置底窗口 / 桌面壁纸层 / 屏保 | 左边时钟和当前状态，右边今日课表，底部一条值日 |
| 窄版 | 右侧停靠 | 左栏时钟、正在上课、今日值日，右栏整条课表 |

## 快速开始

1. 用 Visual Studio 打开 `NEWCLASSroom.sln`（新版也可以打开 `NEWCLASSroom_solution.slnx`）
2. 生成并运行，屏幕会变成班牌，右下角托盘出现蓝色「班」字图标
3. 首次运行会自动生成一份示例数据，可以直接看到效果
4. 右键托盘图标 → **设置**，在「手机端」页签可以看到局域网地址和二维码
5. 手机连同一个 WiFi，扫码打开，输入口令（默认 `1234`），就能发消息和改课表


## 显示方式

| 方式 | 表现 | 说明 |
|---|---|---|
| 置底窗口 | 铺满全屏，压在 Z 序最底 | 稳定，但会挡住桌面图标 |
| 右侧停靠 | 只占屏幕右半边 | 左侧桌面图标照常可见，用窄版界面 |
| 桌面壁纸层 | 挂到资源管理器桌面层 | 图标浮在上面，最像真壁纸；个别 Windows 版本挂不上会自动退回置底 |

切换后立即生效，不需要重启程序。

## 外网访问（可选）

老师不在学校 WiFi 时也能发消息，需要一条隧道。程序不绑定具体厂商，只负责把命令跑起来：

- 「设置 → 外网访问 → 启动命令」填隧道客户端的命令行，例如
  `{app}\frp\frpc.exe -c {app}\frp\frpc.toml`
  其中 `{app}` 会自动替换成程序所在目录，`{port}` 替换成端口号
- 「公网地址」填隧道给你的访问地址，二维码会跟着换成它

> **注意**：`frpc.toml` 里含隧道 token，属于个人凭据。仓库里不包含任何隧道客户端，需要自己下载后放到程序目录下的 `frp/` 文件夹。

## 项目结构

```
NEWCLASSroom_solution/
├─ NEWCLASSroom/                 主程序
│  ├─ Models/AppData.cs          数据结构与默认值
│  ├─ Services/                  课程引擎、存储、显示、网络、隧道等
│  ├─ Views/                     四个窗口（宽屏班牌、窄版班牌、消息弹窗、设置）
│  ├─ Web/index.html             手机端页面，编译时嵌入 exe
│  └─ App.xaml.cs                程序入口与托盘
├─ _check/                       开发期自检工具，不参与正式构建
├─ docs/技术文档.md               模块与方法说明
└─ NEWCLASSroom.sln
```

## 数据存储

所有数据存在程序目录下的 `data/classboard.json`，包括班级信息、作息时间表、课表、值日表和设置。每天会留一份备份 `classboard.YYYYMMDD.json`。

如果程序装在只读目录（比如 Program Files），数据会自动落到 `%APPDATA%\NEWCLASSroom`。

## 开发自检

`_check/` 下有一套不依赖 Visual Studio 的自检工具，用来在没有完整 IDE 的环境里验证代码：

```bash
cd _check
python gen_stubs.py ../NEWCLASSroom stubs/XamlStubs.cs   # 从 XAML 生成控件桩，供类型检查
dotnet build BuildCheck.csproj                           # 编译全部 C# 逻辑
dotnet build Smoke.csproj && ./bin/Debug/net48/Smoke.exe # 冒烟测试：课程判定 + 手机端接口
python validate_xaml.py ../NEWCLASSroom                  # 检查 XAML 控件名与事件处理函数
```

## 已知限制

- 桌面壁纸层依赖资源管理器的 WorkerW 结构，个别 Windows 版本挂不上，程序会自动退回置底模式
- 置底模式会挡住桌面图标，需要看桌面时用托盘菜单收起班牌
- 公网访问地址无法自动推导，隧道种类太多，只能手动填一次
- 面向单个班级设计，多班同屏需要扩展数据模型
